# Strassenverkehrs-Simulation

Strassenverkehr in Wiesbaden-Erbenheim
Eine Simulation im Computer

Hier finden Sie die Beispiele zu einem Vortrag, den ich einmal gehalten habe.

Ziel meines Vortrages war die Vorstellung eines Programms zur Simulation von Strassenverkehr.
Sie finden dieses Programm hier: https://sumo.dlr.de/docs/Installing/index.html

Es gibt dieses Programm für Windows, Mac und Linux. Unter dem angegebenen Link finden Sie Hinweise zur Installation.

In meinem Vortrag habe ich Modelle vorgestellt. Folgende Modelle existieren z.Z.:
- Erbenheim.initial
  ein Modell, das unverändert von OpenStreetMap übernommen wurde
  
- Erbenheim.basis
  am initialen Modell wurden einige Korrekturen vorgenommen (Tilpetersresch für Autos gesperrt, in der Köhlstrasse wurde die Einbahnstrasse verlängert,....)

- Erbenheim.Sperrung.Berliner
  eine reale Sperrung wurde im Modell nachgebildet, um Vergleiche mit der Realität zu ermöglichen
    
- Erbenheim.Sperrung.Barbarossa
  eine weitere Sperrung eines Abschnitts. Auch hier kann man das Verhalten der "Autofahrer" im Modell mit dem Verhalten in der Realität abgleichen
  
- Erbenheim.Unfall.Autobahn
  ein Unfall auf der Autobahn A66, der zur Vollsperrung der Autobahn führte 
  
Die Erstellung eigener Modelle wird hier beschrieben: https://sumo.dlr.de/docs/Tutorials/OSMWebWizard.html
